# Security

Microsoft is committed to the security of our software products and services, including all source code repositories managed under our GitHub organizations: [Microsoft](https://github.com/Microsoft), [Azure](https://github.com/Azure), [DotNet](https://github.com/dotnet), [AspNet](https://github.com/aspnet), and [Xamarin](https://github.com/xamarin).

If you discover a security vulnerability in any Microsoft-owned repository that meets [Microsoft's definition of a security vulnerability](https://aka.ms/security.md/definition), please report it as described below.

## Reporting Security Issues

**Do not report security vulnerabilities via public GitHub issues.**

Instead, submit your report to the Microsoft Security Response Center (MSRC) at [https://msrc.microsoft.com/create-report](https://aka.ms/security.md/msrc).

If you prefer not to log in, email [secure@microsoft.com](mailto:secure@microsoft.com). Whenever possible, encrypt your message using our PGP key, available here: [Microsoft Security Response Center PGP Key](https://aka.ms/security.md/msrc/pgp).

You should receive a response within 24 hours. If you do not, please follow up to confirm we received your report. Additional information is available at [microsoft.com/msrc](https://www.microsoft.com/msrc).

Please include as much of the following information as possible to help us address the issue quickly:

- Type of issue (e.g., buffer overflow, SQL injection, cross-site scripting)  
- Full paths of affected source files  
- Location of affected code (tag/branch/commit or direct URL)  
- Any special configuration required to reproduce the issue  
- Step-by-step instructions to reproduce the issue  
- Proof-of-concept or exploit code, if available  
- Potential impact and ways an attacker might exploit the issue  

Complete reports may also help increase a bug bounty award. For details on active programs, see the [Microsoft Bug Bounty Program](https://aka.ms/security.md/msrc/bounty).

## Preferred Languages

We prefer all communications to be in English.

## Policy

Microsoft adheres to the principle of [Coordinated Vulnerability Disclosure](https://aka.ms/security.md/cvd).
