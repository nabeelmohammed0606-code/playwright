# Contributing

## Choose an Issue

Playwright **requires an issue** for every contribution, except minor documentation updates. For your first contribution, we strongly recommend picking an issue labeled [open-to-a-pull-request](https://github.com/microsoft/playwright/issues?q=is%3Aissue%20state%3Aopen%20label%3Aopen-to-a-pull-request).

If you have a bug or feature idea but cannot find a related issue, **file an issue first**. This facilitates discussion and may provide early feedback before creating a pull request.

Write Documentation
